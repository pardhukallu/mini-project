# Phase 2 — Exposure Data Providers

The original paid-provider integration was replaced with XposedOrNot.

- Email breach check: `GET https://api.xposedornot.com/v1/check-email/{email}`. No API key is required.
- Email response normalization reports breach names only; missing dates, domains, record counts, and data classes remain blank.
- HTTP 429 and upstream errors are surfaced to the user and are never treated as clean results.
- Scan evidence is persisted and used by the privacy scoring service.
